## 追加：部署平台改为腾讯云 EdgeOne Pages 免费版（PRD v1.1，457 行，决策 D12）

- EdgeOne Pages **已支持 Python 3.10 + FastAPI（ASGI Framework 模式）**，后端无需改写成 Node。入口固定 `cloud-functions/api/index.py`，平台把 `api` 目录作为路由前缀并自动剥离 → FastAPI 内部路由不带 `/api`。
- 前后端同一项目同一域名，**无 CORS**。构建命令 `cd frontend && npm ci && npm run build`，输出 `frontend/dist`，SPA 需配回退到 index.html。
- 免费版关键配额：Cloud Functions 100 万次/月、代码包 128MB、body 6MB、超时默认 30s（可调 120s）、50 万 GB-s/月；项目 40 个、构建 500 次/月；KV/Blob 各 1GB（未使用）。
- 坑：EdgeOne 默认项目域名是**限时预览链接（约 3 小时）**，长期必须绑自定义域名；大陆加速节点要求域名 ICP 备案，否则只能选「全球可用区（不含中国大陆）」跨境访问。
- 因此新增实现约束：Excel 导入禁用 pandas（会吃 60–80MB 包体），改用 openpyxl。
- Next.js/Vercel 相关的 4.5MB body 限制已记为历史对比，方案内以 6MB 为准。
