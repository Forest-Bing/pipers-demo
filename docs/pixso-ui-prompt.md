## 提示词正文（复制这一段）

请为一个 **B 端内部使用的「国家管网管道巡检标记系统」** 设计一套 **响应式 Web 端高保真 UI**。这是一个地图 + 现场标记工具，使用者是管道巡线工、段长、技术员和后台管理员。产品必须在 **电脑浏览器和手机浏览器** 上都能正常使用，因此需要同时输出 **手机端（375 宽）和桌面端（1440 宽）** 两套断点的画板，并共享同一套设计语言。

界面语言全部为 **简体中文**，不要出现英文占位文案、不要用 Lorem ipsum。所有数据都用真实感的中文示例，例如姓名「张建国」、职位「巡线工」、手机号「138****6027」、管段名「西气东输二线 中卫—靖边段」、关键点编号「JMZ-0421」、阀室名「3# 阀室」、标记描述「K12+300 处管线上方发现第三方施工取土，已现场制止并拍照留证」。

### 一、整体视觉风格

**风格关键词：苹果风、Liquid Glass（液态玻璃）、克制的专业工具感。**

- 字体：`-apple-system, "PingFang SC", "Helvetica Neue", sans-serif`。标题字重 600，正文 400，数字用等宽 `SF Mono / ui-monospace`。
- 主色板：
  - 警告红 `#FF3B30`（警示标记专用，全站只用于此）
  - 信息蓝 `#0A84FF`（普通信息标记、主按钮、当前定位）
  - 系统背景 `#F2F2F7`，主文字 `#1C1C1E`，次级文字 `#8E8E93`，分隔线 `rgba(60,60,67,0.12)`
  - 成功绿 `#34C759`（仅用于"已同步"状态）
- 玻璃面板规范（移动端的主视觉手段，务必体现）：
  - 填充 `rgba(255,255,255,0.55)`
  - 背景模糊 `blur(20px) saturate(180%)`
  - 1px 内描边高光 `inset 0 1px 0 rgba(255,255,255,0.75)`
  - 大圆角 20–28px
  - 外阴影极轻：`0 8px 32px rgba(0,0,0,0.08)`
- 桌面端的管理后台 **不要滥用玻璃**：表格、表单等数据密集区域使用实色白卡片（`#FFFFFF`，圆角 16px，1px 边框 `rgba(60,60,67,0.08)`），仅顶部栏、左侧导航和弹层保留玻璃质感。玻璃 + 密集数据会牺牲可读性。
- 圆角：小控件 10px，卡片 16–20px，玻璃浮层 24–28px。不使用全圆角胶囊做卡片。
- 图标：线性图标，1.5px 描边，圆角端点，风格接近 SF Symbols，不要填充式图标。
- 动效标注：只做位移和透明度，曲线 `cubic-bezier(.32,.72,0,1)`，时长 240–320ms，**不做弹跳**。请用标注或注释说明关键转场。
- 禁止：霓虹渐变、玻璃拟态的深色版本、卡通插画、彩色大色块、渐变按钮、过于花哨的阴影。

### 二、地图视觉规范（所有含地图的画板统一遵守）

地图底图用 **抽象简化风格**：底色 `#F7F7F5`，主干路网 `#FFFFFF` 1.5px 带浅灰描边，水系 `#DCE9F5`，绿地 `#E8F0E4`，不画真实文字地名（用极淡的灰色占位文字即可）。

四个图层的视觉必须是这个层级关系，**地图图层永远在玻璃面板之下**：

1. **管道线**：深石板灰 `#45525E`，2.5px 实线，外面包一层 4px 的半透明白描边保证在浅色地图上可见。多条管段用不同灰阶。
2. **关键点**（三种，必须视觉可区分）：
   - 加密桩：12px 圆点，`#5B6B7C`，2px 白描边
   - 智能测试桩：12px 圆点，`#30B0C7`，外加一圈 20px 的淡青色光晕（暗示信号）
   - 阀室：14px 圆角方形，`#8E7BEF`，2px 白描边
   - 缩小时按类型聚合为气泡：白色玻璃圆 34px，深色数字，底部带一个 6px 的小三角指向聚合中心；>99 显示「99+」
3. **标记**：水滴形图钉，尖端指向坐标点，24px 高，顶部圆形内含白色小图标。警告标记红色 `#FF3B30` + 感叹号图标；普通信息蓝色 `#0A84FF` + 信息图标。所有移动端标注加 2px 白描边和轻微投影。
4. **当前位置**：蓝点 `#0A84FF` 8px + 24px 半透明白色圆环 + 最外层 40px 极淡蓝色呼吸环。

地图控件：右下角竖向排列的玻璃圆形按钮（定位、图层、放大、缩小），44px 直径，间距 12px。左上角为地图比例尺和「数据更新于 2 分钟前」的极小字说明。

## 设计侧待你确认的假设

1. **范围**：手机端 8 屏 + 桌面 4 屏，覆盖 PRD 里所有有界面的功能。PRD 未提及的「审计日志」「关键点台账」「概览」只做导航项占位，不单独出画板。
2. **断点**：手机按 375 宽、桌面按 1440 宽。实际开发建议 768 为断点，中间尺寸走手机布局拉伸。
3. **地图底图**：用抽象简化地图，方便后续真机替换。如果你有高德截图，可替换提示词第二节的底图描述。
4. **颜色**：警告红 `#FF3B30`、信息蓝 `#0A84FF` 取 iOS 系统色。若国家管网有品牌色规范，需要替换。
5. **不做的**：注册页、忘记密码页、消息中心、统计报表、深色模式——PRD 均明确排除。
6. **后台是否要手机版**：PRD 说管理员是纯后台角色，且验收标准要求普通用户「界面无任何管理入口」。我按「后台只做桌面」处理，手机访问后台不在本期范围。
