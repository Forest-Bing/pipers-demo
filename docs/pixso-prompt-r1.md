# 第 1 轮提示词 · 只发给 Pixso 这一条

> 整段复制，不要改动。本轮只做 2 个画板，目的是先把「地图 + 玻璃 + 图钉」的观感定下来，后面 10 屏都以它为准。

---

请为一个 **B 端内部使用的「国家管网管道巡检标记系统」** 设计 **响应式 Web 端**的高保真 UI。这是一个地图 + 现场标记工具，使用者是管道巡线工、段长、技术员。产品要在电脑和手机浏览器上都能用。

本轮只需要输出 **2 个画板**：手机端的地图主界面、桌面端的地图主界面。这两个画板是整套设计的风格基准，请把细节做足。

界面语言全部为 **简体中文**，不要英文占位文案、不要 Lorem ipsum。数据用真实感的中文示例：姓名「张建国」、管段名「西气东输二线 中卫—靖边段」、关键点编号「JMZ-0421」、阀室名「3# 阀室」、标记描述「K12+300 处管线上方发现第三方施工取土，已现场制止并拍照留证」。

## 一、整体视觉风格

**关键词：苹果风、Liquid Glass（液态玻璃）、克制的专业工具感。**

- 字体：`-apple-system, "PingFang SC", "Helvetica Neue", sans-serif`。标题 600，正文 400，数字用等宽字体。
- 色板：
  - 警告红 `#FF3B30`（全站只用于警示标记）
  - 信息蓝 `#0A84FF`（普通信息标记、主按钮、当前定位）
  - 系统背景 `#F2F2F7`，主文字 `#1C1C1E`，次级文字 `#8E8E93`，分隔线 `rgba(60,60,67,0.12)`
  - 成功绿 `#34C759`（仅用于"已同步"）
- 玻璃面板规范（本产品的核心视觉手段，务必体现）：
  - 填充 `rgba(255,255,255,0.55)`
  - 背景模糊 `blur(20px) saturate(180%)`
  - 1px 内描边高光 `inset 0 1px 0 rgba(255,255,255,0.75)`
  - 大圆角 20–28px
  - 外阴影极轻：`0 8px 32px rgba(0,0,0,0.08)`
- 圆角：小控件 10px，卡片 16–20px，玻璃浮层 24–28px。不用全圆角胶囊做卡片。
- 图标：线性图标，1.5px 描边，圆角端点，接近 SF Symbols 风格，**不要填充式图标**。
- 动效标注：只做位移和透明度，曲线 `cubic-bezier(.32,.72,0,1)`，240–320ms，**不做弹跳**。
- 禁止：霓虹渐变、深色玻璃拟态、卡通插画、彩色大色块、渐变按钮、过重阴影。

## 二、地图视觉规范（两个画板统一遵守）

地图底图用 **抽象简化风格**：底色 `#F7F7F5`，主干路网 `#FFFFFF` 1.5px 带浅灰描边，水系 `#DCE9F5`，绿地 `#E8F0E4`，不画真实地名（用极淡灰色占位文字即可）。

四个图层的层级关系：**所有地图元素永远在玻璃面板之下**。

1. **管道线**：深石板灰 `#45525E`，2.5px 实线，外包一层 4px 半透明白描边，保证在浅色地图上可见。
2. **关键点**（三种，必须视觉可区分）：
   - 加密桩：12px 圆点 `#5B6B7C`，2px 白描边
   - 智能测试桩：12px 圆点 `#30B0C7`，外圈 20px 淡青光晕（暗示信号）
   - 阀室：14px 圆角方形 `#8E7BEF`，2px 白描边
   - 缩小时按类型聚合为气泡：白色玻璃圆 34px，深色数字，底部带 6px 小三角指向聚合中心，超过 99 显示「99+」
3. **标记**：水滴形图钉，尖端指向坐标，24px 高，顶部圆形内含白色小图标。警告为红色 `#FF3B30` + 感叹号；普通信息为蓝色 `#0A84FF` + 信息图标。均加 2px 白描边和轻微投影。
4. **当前位置**：蓝点 `#0A84FF` 8px + 24px 半透明白圆环 + 最外层 40px 极淡蓝呼吸环。

地图控件：右下角竖向玻璃圆形按钮组（定位、图层、放大、缩小），44px 直径，间距 12px。

## 三、画板 A：手机端「地图主界面」· 375 × 812

- 铺满全屏的抽象地图，四个图层都要出现：**3 个红色警告标记、4 个蓝色信息标记、两种关键点图标、2 个聚合气泡、1 个当前位置光圈**。
- **顶部**：横向玻璃胶囊（左右各留 16px，高 48px），左侧放大镜 + 灰色提示「搜索关键点编号 / 名称」，右侧圆形头像按钮（显示姓氏「张」）。
- **胶囊下方**：一条细玻璃状态条。左边红点 +「3 条警告」、蓝点 +「4 条信息」；右边一个「仅看警告」筛选胶囊。注意：产品不做严重程度分级，**只能按类型筛选**。
- **右下角**：竖向玻璃控制按钮组（定位、图层、放大、缩小）。
- **底部**：玻璃悬浮卡片，露出约 30% 高度，可上滑展开。顶部有 36×4px 圆角拖拽指示条；标题行「附近标记」+ 右侧「共 7 条」；下方横向滚动的标记缩略列表，每条含类型色点、描述前 20 字、距离「120m」、时间「14:32」。
- **右下角卡片上方**：悬浮圆形主操作按钮，56px，信息蓝，白色「+」，柔光阴影。这是全屏唯一的实色强调元素。
- **左下角**：小玻璃胶囊显示「待同步 2 条」+ 旋转的同步图标。这个元素必须有，代表弱网草稿状态。

## 四、画板 B：桌面端「地图主界面」· 1440 × 900

- **左侧 380px 玻璃侧栏**（贴左边、上下通栏、圆角只在右侧 24px）：
  - 顶部产品名 + 小 Logo
  - 搜索框
  - 类型筛选胶囊
  - 「附近标记」竖向列表 8 条，每条含类型色点、描述、距离、时间、缩略图小方块
  - 侧栏底部用户信息行（头像 + 「张建国 · 巡线工」）
- **右侧全屏地图**占满剩余宽度，图层元素同上但尺寸放大一档：标记图钉 28px，聚合气泡 40px。
- 右下角横向排列的玻璃控制按钮组 + 一个**带文字的主按钮**「添加标记」（蓝底白字 + 加号，不是圆形）。
- 左上角地图上叠加一个玻璃胶囊，显示「西气东输二线 · 中卫—靖边段」，右侧带切换管段的下拉箭头。

## 五、交付要求

- 只输出这 2 个画板，横向排列，画板名为「地图主界面 - 手机」和「地图主界面 - 桌面」。
- 画板右下角用 12px 灰字标注「断点：Mobile 375 / Desktop 1440」。
- 标记图钉、关键点图标、聚合气泡、玻璃卡片要做成**可复用组件**，不要每处重画。
- **不要输出深色模式、不要套 iOS 手机外壳、不要画系统状态栏和底部 Home 条**——这是 Web 页面，不是原生 App。
- 两个画板必须是同一套色板、圆角、玻璃参数，不要各设计一套风格。
